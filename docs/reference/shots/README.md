# 镜头卡（参考资料）

这些文档是**创意参考**，不参与任何运行时流程（scan / creative build / mix 都不会读它们）。

## 什么时候用

- 设计新引擎、变体或文案节奏时，先按 `INDEX.md` 的分类找 1–3 张相关卡片；
- 只读需要的卡片，不要整目录通读；
- 卡片描述的是**方法与判例**（运镜、转场、字体运动、节奏），不是可复制代码。

## 怎么找

1. 打开 `INDEX.md`，按类别扫标题：camera / effects / interaction / opening / outro / rhythm / transition / typography / ui-entrance；
2. 用关键词搜索，例如 `grep -ril "carry" docs/reference/shots`；
3. 只有确认要复刻某种手法时，才展开对应卡片。

## 注意

- 卡片参数按横屏 1920×1080 标定，竖屏使用需按 1080×1920 重标；
- `INDEX.md` 中标注「未随包提供」的卡片不在当前内容包里；
